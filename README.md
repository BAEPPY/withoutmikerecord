# withoutmikerecord

**마이크 없이, Chrome / Edge의 현재 탭에서 재생되는 소리만 녹음하는 확장 프로그램입니다.** 페이지의 음악, 영상, 강의 등의 오디오를 녹음하고 **오디오 전용 MP4 파일**로 기기에 저장합니다. 한국어 팝업에서 녹음 시작, 일시 정지, 재개, 종료, 미리 듣기, 구간 선택 및 저장을 조작할 수 있습니다.

## 설치

Chrome 또는 Microsoft Edge **최신 안정 버전**을 사용하세요. MP4 녹음 지원은 브라우저와 운영체제에 따라 달라집니다. 지원하지 않는 환경에서는 업데이트 안내가 표시됩니다. 현재는 확장 프로그램 스토어 대신 개발자 모드로 설치합니다.

1. [GitHub 저장소](https://github.com/BAEPPY/withoutmikerecord)에서 이 구현이 포함된 브랜치를 선택한 뒤 **Code → Download ZIP**으로 내려받고 압축을 풉니다. PR을 통해 확인 중이라면 해당 PR의 작업 브랜치를 선택하세요. Git을 사용한다면 저장소를 복제하고 해당 브랜치로 체크아웃해도 됩니다.
2. Chrome에서는 `chrome://extensions`, Edge에서는 `edge://extensions`를 주소창에 입력합니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다** / **압축 풀린 파일 로드**를 누릅니다.
4. 압축을 푼 저장소 안의 **`extension` 폴더**를 선택합니다. `manifest.json`이 있는 폴더여야 합니다.
5. 브라우저 도구 모음의 확장 프로그램 메뉴에서 **탭 소리 녹음**을 고정하면 편리합니다.

별도로 제공된 `withoutmikerecord-1.2.0.zip` 설치용 파일은 압축을 푼 폴더 자체를 선택하세요. 이 ZIP의 최상위에 `manifest.json`이 있습니다. 저장소 ZIP에서는 `extension` 폴더를 선택합니다.

소스를 수정하거나 새 버전을 받은 뒤에는 확장 프로그램 관리 화면에서 새로고침을 누릅니다. 새로고침하기 전에 진행 중인 녹음을 끝내고 파일을 저장하세요.

## 사용 방법

1. 녹음할 웹페이지를 열고 오디오를 재생합니다.
2. 그 탭에서 확장 프로그램 아이콘을 **한 번** 눌러 연결합니다. **이 탭에 연결됨** 안내가 나오면 팝업을 닫아도 됩니다. 페이지에서 **1**을 누르면 녹음을 시작합니다. 팝업의 **녹음 시작** 버튼도 사용할 수 있습니다.
3. 필요하면 **일시 정지** / **녹음 재개**를 사용합니다. 일시 정지한 시간은 녹음 시간에서 제외됩니다.
4. 페이지에서 **2**를 누르면 녹음이 끝납니다. 확장 아이콘에 저장 표시가 나타나면 아이콘을 눌러 파일을 확인합니다. 팝업의 **녹음 끝내기** 버튼도 사용할 수 있습니다.
5. **전체 저장 · .mp4**를 누르거나 아래 방법으로 원하는 구간만 저장합니다. 브라우저의 저장 절차를 완료한 뒤 팝업의 **다운로드 완료** 메시지나 브라우저 다운로드 목록에서 저장 결과를 확인하세요.
6. **새 녹음**을 누르면 다음 녹음을 준비합니다. 저장을 완료하지 않은 파일은 삭제 전에 확인합니다.

녹음 중 팝업을 닫거나 다른 탭으로 이동해도 처음 선택한 탭의 녹음이 이어집니다. 확장 프로그램 아이콘을 다시 누르면 녹음 상태를 확인할 수 있습니다. 녹음하는 동안 페이지의 소리도 계속 들을 수 있습니다. 다운로드를 취소하거나 저장에 실패하면 파일을 보관하므로 같은 저장 버튼을 다시 누르세요.

숫자 **1 / 2**는 연결된 페이지와 확장 프로그램 팝업에서 작동합니다. 페이지의 재생 버튼을 클릭해 팝업이 닫혀도 사용할 수 있습니다. **새로고침하거나 다른 페이지로 이동한 뒤에는 확장 아이콘을 다시 눌러 연결하세요.** 연결된 페이지에서는 사이트의 기존 1 / 2 단축키보다 녹음 단축키가 우선합니다. 글을 입력하는 입력창에서는 숫자가 그대로 입력되며, 키를 길게 눌러도 명령을 반복하지 않습니다. 주소창이나 다른 출처의 영상 프레임에 포커스가 있으면 숫자 단축키가 전달되지 않을 수 있습니다.

**확장 아이콘을 열지 않고 바로 사용하려면 `Alt+Shift+1`로 시작하고 `Alt+Shift+2`로 끝낼 수 있습니다.** 녹음할 탭을 선택하고 사용하세요. 다른 확장이나 운영체제 단축키와 충돌하면 Chrome의 `chrome://extensions/shortcuts` 또는 Edge의 `edge://extensions/shortcuts`에서 키를 확인·변경하세요.

일시 정지 상태에서도 **2**로 녹음을 끝낼 수 있습니다. 페이지 단축키와 `Alt+Shift+2`는 해당 탭의 녹음만 종료합니다. 녹음 완료 상태에서 **1**을 눌러도 기존 파일을 지우지 않습니다. 새 녹음은 저장 후 **새 녹음** 버튼으로 준비합니다.

## 원하는 구간만 잘라 저장하기

1. 녹음을 끝내면 **듣고, 원하는 구간만 저장하기**가 나타납니다. 오디오 재생 막대로 녹음 내용을 확인합니다.
2. **시작 (초)**와 **끝 (초)**를 입력합니다. 예를 들어 `10.25`와 `25.75`를 입력하면 약 15.50초 구간을 저장합니다. **0.01초 단위**로 입력할 수 있으며, 입력을 마치면 소수 둘째 자리까지 표시합니다.
3. 재생 막대 아래 **현재 위치 / 전체 길이**도 `00:10.25`처럼 소수 둘째 자리까지 보입니다. 재생 막대를 움직인 뒤 **현재 위치를 시작으로** / **현재 위치를 끝으로**를 눌러 구간을 지정할 수도 있습니다.
4. **선택 구간 듣기**로 확인합니다. 선택한 끝에 도달하면 미리 듣기가 멈춥니다.
5. **선택 구간 저장 · .mp4**를 누릅니다. 파일명에는 선택 시간이 포함됩니다.

전체 원본은 새 녹음을 시작하기 전까지 유지됩니다. 구간을 바꿔 여러 파일로 저장하거나 **전체 저장**으로 원본을 저장할 수 있습니다. 유효한 선택 시간은 팝업을 닫았다 열어도 유지됩니다. 저장이 취소된 경우에도 같은 구간을 다시 저장할 수 있습니다.

자르기는 기기 안에서 MP4 오디오 데이터를 복사하며 재인코딩하거나 서버에 전송하지 않습니다. 0.01초는 표시·입력 단위입니다. 오디오 프레임 경계에서 자르기 때문에 실제 파일의 시작·끝은 지정 시간과 약 0.1초 차이가 날 수 있습니다. 시작은 0초 이상, 끝은 시작보다 뒤이면서 전체 녹음 길이 이하여야 합니다. 구간 정보를 읽지 못하면 전체 저장은 계속 사용할 수 있습니다.

## 지원 범위와 제한

- 녹음을 시작한 **한 개 탭의 오디오만** 수집합니다. 마이크, 다른 탭, 운영체제 전체 소리는 녹음하지 않습니다.
- Chrome / Edge의 일반 웹페이지용입니다. 브라우저 설정 화면, 새 탭, `chrome://` / `edge://` 페이지, 확장 프로그램 스토어 등 보호된 페이지는 녹음할 수 없습니다. 일반 웹페이지에서 다시 시도하세요.
- DRM 등으로 보호된 콘텐츠는 녹음이 차단되거나 무음일 수 있습니다. 페이지와 브라우저의 캡처 정책에 따라 결과가 달라집니다.
- 저장 형식은 영상 없이 소리만 포함한 **MP4**입니다. 브라우저의 `MediaRecorder`로 MP4를 직접 녹음합니다. 파일 확장자만 바꾸거나 별도 변환 서비스를 사용하지 않습니다.
- 브라우저와 운영체제에 따라 오디오 코덱이 달라집니다. **AAC를 우선 사용**하고, 지원 여부에 따라 **MP4 / Opus** 또는 브라우저의 MP4 기본 코덱을 사용합니다. MP4 / Opus는 일부 플레이어에서 지원하지 않을 수 있으므로 **최신 Chrome / Edge 또는 VLC**에서 재생하세요.
- MP4 녹음을 지원하지 않으면 시작 전에 안내합니다. Chrome / Edge를 최신 버전으로 업데이트한 뒤 다시 시도하세요. 업데이트 후에도 지원되지 않는 환경에서는 녹음을 시작할 수 없습니다.
- 동시에 한 개의 녹음만 가능합니다. 새 녹음 전에 기존 녹음을 저장하거나 삭제하세요.
- 녹음은 **최대 2시간 또는 128 MiB(팝업에는 128 MB로 표시)**에 도달하면 자동으로 끝납니다. 오디오 데이터를 수집하는 주기 때문에 파일 크기가 한도를 조금 넘을 수 있습니다.
- 녹음 파일은 저장 전까지 브라우저 메모리에 보관됩니다. **브라우저 종료, 확장 프로그램 새로고침·비활성화, 충돌 시 저장하지 않은 녹음이 사라집니다.** 긴 녹음은 나눠서 저장하는 것을 권장합니다.
- 녹음하던 탭이 닫혀 스트림이 끝나면 녹음이 종료됩니다. 확장 프로그램 팝업을 다시 열어 생성된 파일을 저장하세요.

## 개인정보와 권한

오디오 처리는 기기 안에서 이루어지며 서버 업로드, 외부 라이브러리 요청, 분석 추적을 사용하지 않습니다. 마이크 권한도 요청하지 않습니다. 브라우저가 녹음 중인 탭에 캡처 표시를 보일 수 있습니다.

| 권한 | 사용 목적 |
| --- | --- |
| `activeTab` | 사용자가 확장 아이콘이나 브라우저 단축키로 선택한 현재 탭에 접근합니다. |
| `scripting` | 확장 아이콘을 누른 탭에 1 / 2 단축키를 연결합니다. 모든 사이트에 대한 상시 접근 권한은 요청하지 않습니다. |
| `tabCapture` | 사용자가 시작한 탭의 오디오 스트림을 캡처합니다. |
| `offscreen` | 팝업을 닫아도 별도 문서에서 녹음과 오디오 재생을 유지합니다. |
| `downloads` | 생성한 파일을 저장하고 다운로드 완료·중단 상태를 확인합니다. |

## 개발 및 확인

빌드 없이 `extension` 폴더를 바로 로드할 수 있습니다. 저장소 루트에서 Node.js로 자동 테스트를 실행합니다.

```sh
npm test
npm run check
npm run package
```

Node.js 22 이상을 권장합니다. 패키징에는 Python 3이 필요하며 `dist/withoutmikerecord-1.2.0.zip`을 생성합니다. 실행을 위해 추가로 설치할 의존성이나 빌드 단계가 없습니다. MP4 구간 처리를 위한 MP4Box.js 2.4.1은 확장 프로그램 안에 포함되어 있으며 라이선스와 출처는 `extension/vendor/mp4box/`에 있습니다.

`python3 scripts/browser-smoke.py`는 Python Playwright, Chromium, FFmpeg가 있는 환경에서 합성 테스트 음원으로 실제 MP4 인코딩과 팝업을 닫은 페이지 단축키 조작, 0.01초 표시, 팝업 조작, 구간 미리 듣기, 구간 저장 및 선택값 유지, 전체 원본 저장을 확인합니다. 잘린 MP4의 오디오 주파수도 확인해 선택한 시간대의 내용이 들어가는지 검사합니다. Chromium 경로는 `CHROMIUM_PATH`로 지정할 수 있습니다. 이 검사는 실제 탭 캡처 권한을 검사하지 않습니다.

개발 환경에서 녹음·구간 선택·자르기·정리·저장 재시도 자동 테스트와 JS 구문 검사를 통과했습니다. Chromium 154에서 MP4/Opus 파일 생성과 구간 자르기, 오디오 트랙만 포함되는지 확인, FFmpeg 디코딩, 팝업 조작을 확인했습니다. AAC와 Opus의 잘린 파일 모두 별도로 디코딩을 확인했습니다. 확장 프로그램 설치는 개발 환경의 브라우저 관리자 정책으로 차단되어 실제 `tabCapture`와 다운로드 저장 창은 수동 검증이 남아 있습니다.

Chrome / Edge에 직접 설치한 뒤 아래 항목을 확인하세요.

- [ ] 일반 HTTPS 페이지에서 소리를 재생하고 녹음을 시작한다. **마이크 권한 요청이 없는지**, 녹음 시간과 오디오 표시가 변하는지 확인한다.
- [ ] 확장 아이콘을 한 번 눌러 연결한 뒤 팝업을 닫고 **페이지에서 1**로 시작한다. 영상 재생 버튼을 클릭하고 **2**로 종료한다. 새로고침 후 다시 연결되는지도 확인한다.
- [ ] 아이콘을 열지 않은 새 탭에서 **Alt+Shift+1 / Alt+Shift+2**로 시작·종료한다.
- [ ] 팝업에서도 **1**로 시작하고 **2**로 종료한다. 일시 정지 후에도 **2**로 종료되는지, 구간 입력란에서 `12`를 입력하면 숫자가 그대로 들어가는지 확인한다.
- [ ] 녹음 중에도 페이지 소리가 계속 들리는지 확인한다. 마이크로 말하거나 다른 탭에서 소리를 재생해도 저장 파일에는 녹음 대상 탭의 소리만 포함되는지 확인한다.
- [ ] 팝업을 닫고 잠시 후 다시 열었을 때 녹음이 계속되는지 확인한다. 다른 탭으로 이동해도 처음 탭이 녹음 대상인지 확인한다.
- [ ] 일시 정지 중 시간이 멈추는지 확인한다. 재개하고 저장한 파일에 정지 구간이 포함되지 않는지 확인한다.
- [ ] 녹음을 끝내고 저장한다. 다운로드 완료 표시를 확인하고 `.mp4` 파일을 최신 Chrome / Edge 또는 VLC에서 재생해 오디오와 길이를 확인한다.
- [ ] 시작·끝 시간을 `0.25`, `1.75`처럼 지정하고 현재 위치가 0.01초까지 표시되는지 확인한다. 미리 듣고 선택 구간을 저장한다. 파일에 해당 구간만 들어가는지 확인한다. 전체 저장으로 원본도 저장할 수 있는지 확인한다.
- [ ] 시작·끝의 순서를 바꾸거나 녹음 길이를 초과하는 값을 입력한다. 구간 저장은 비활성화되고 전체 저장은 가능한지 확인한다.
- [ ] 선택 시간을 바꾼 뒤 팝업을 닫고 다시 연다. 선택값이 유지되고 미리 듣기는 팝업 종료 시 멈추는지 확인한다.
- [ ] 저장 창을 취소하거나 다운로드를 중단한다. 팝업을 다시 열어 파일을 다시 저장할 수 있는지 확인한다.
- [ ] 저장하지 않은 상태에서 **새 녹음**을 눌렀을 때 삭제 확인이 표시되고, 취소하면 기존 녹음이 유지되는지 확인한다.
- [ ] 녹음 중 대상 탭을 닫는다. 다른 탭에서 팝업을 열어 녹음이 종료되고 파일을 저장할 수 있는지 확인한다.
- [ ] 브라우저 설정 페이지 등 지원하지 않는 탭에서 시작한다. 오류 안내 후 일반 웹페이지에서 다시 녹음할 수 있는지 확인한다.

실제 브라우저 검증 결과는 위 항목을 수행한 환경별로 별도로 기록하세요.
